BANK / PAYMENT PARTNER

Integration expectations

A simple technical walkthrough for the proposed IIT Kharagpur CEP payment collection.

01

Registration system

The conference vendor captures participant information, selected fee category and accepted paper reference, then creates a payment request.

02

Hosted checkout

The payment provider receives a server-created order with registration reference, authorized amount and specified currency (USD or INR).

03

Payment confirmation

The gateway redirects the customer and separately provides verifiable status via API, callback or webhook; the website confirms registration only after verification.

?

Questions for the bank

Confirm these capabilities before beginning real integration.

01 Does the gateway support dynamic order creation and hosted checkout?

02 Can delegates be charged exactly in USD, as well as INR? Is settlement into the designated IIT Kharagpur CEP account in INR?

03 What are the fees, FX conversion methodology, taxes, settlement timelines and supported international cards?

04 Are test credentials, API documentation, return URL support, and authenticated server-to-server payment confirmations available?

05 Can an organizer issue a supplementary payment order linked to an earlier registration?

Security note: GitHub Pages cannot safely hold gateway secret keys or verify bank payment signatures. The live version needs a trusted backend (or bank-approved serverless functions) for these operations.
